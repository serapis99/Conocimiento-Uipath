# Calcular Interés Simple

lo que hacemos en este proyecto es reforzar el conocimiento del uso de `workflows` pasándole argumentos.

## Paquetes a instalar

- `Uipath.System.Activities`: actividad principal de uipath.

## Actividades a usar

- `Input dialog`: pide valores al usuario en esta ocacion le pedimos que seleccione un valor de una lista.
- `assign`: permite asignarle un valor a una variable.
