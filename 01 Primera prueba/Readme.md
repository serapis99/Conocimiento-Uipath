# Primera automatización

En esta automatización hacemos el hola mundo en uipath tener en cuenta que el lenguaje base que se usa es VB. 
## Paquetes a instalar

- `Uipath.System.Activities`: paquete principal de las actividades de Uipath
## Actividades a usar

- `Message box`: crea un cuadro de dialogo.
- `Log message`: Nos permite dejar un mensaje de salida por consola usando `info`, `warn`, `error`.
