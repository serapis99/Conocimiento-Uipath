# Variables

En esta automatización aprendimos el uso de las variables, recordando que tenemos varios tipos como:

- `Boolean`: booleanos verdadero y falso
- `Int32`: números enteros
- `String`: para caracteres o textos.

## Paquetes a instalar

- `Uipath.System.Activities`: paquete principal de las actividades de Uipath

## Actividades a usar

- `Input Dialog`: esta actividad nos permite preguntarle al usuario datos y según la variable tendremos un dato ejemplo si la variable es `String` guardaremos textos y si tenemos un `Int32` guardaremos números. tener presente para capturar posibles errores.
