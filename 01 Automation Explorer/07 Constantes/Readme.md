# Constantes

En este ejercicio aprendemos que tanto las constantes como las variables globales son de un `scope` global lo que hace que se puedan acceder a estos desde cualquier archivo del proyecto, no se sugiere su uso ya que se debe usar el scope mas bajo posible.

## Paquetes a instalar

- `Uipath.System.Activities`: paquete basico de uipath

## Actividades a usar

- `input dialog`: pide datos al usuario
- `invoke workflow file`: permite llamados a otros archivos
- `assign`: asigna valores a variables o argumentos.

## Comandos usados

### tipo variable (Environment)

- `Environment.NewLine`: crea una nueva linea en una cadena de string util para separar datos en una misma cadena.
