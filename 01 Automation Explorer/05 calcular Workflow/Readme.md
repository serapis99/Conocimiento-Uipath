# Calcular 

En este proyecto lo que se hace es entender como funciona los argumentos recordar que tienen prefijos.

- `in_`: el argumento ingresa con datos
- `out_`: el argumento sale con datos
- `io_`: el argumento es de entra y salida de datos.
