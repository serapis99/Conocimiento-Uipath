# Bucles indeterminados

los bucles indeterminados son trozos de código que se repite varias veces mientras se cumple una condición.

- `sequences`:
   - `while`: esta actividad primero valida la condición antes de ejecutar las sentencias de su interior.
   - `do while`: esta actividad ejecuta las sentencias antes de validar lo que hace que aunque sea se ejecute una vez las sentencias.
- `flowchart`:
   - no se tiene actividades lo que se hace es emular el `while` o el `do while` usando las conexiones del flujo y como se necesita una condicion se usa `flow decision`
